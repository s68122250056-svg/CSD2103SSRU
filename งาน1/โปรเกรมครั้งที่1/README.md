กรณีศึกษาที่ 1 : Array
ลำดับการทำงานของข้อมูล
สร้าง Array scores เพื่อเก็บคะแนนนักศึกษาทั้ง 10 คน
กำหนดตัวแปร sum, max, min และ pass สำหรับเก็บผลการคำนวณ
ใช้ for Loop อ่านข้อมูลใน Array ตั้งแต่สมาชิกตัวแรกจนถึงตัวสุดท้าย
ในแต่ละรอบของการวนลูป
แสดงคะแนนของนักศึกษา
นำคะแนนมาบวกเข้ากับ sum
เปรียบเทียบเพื่อหาคะแนนสูงสุด (max)
เปรียบเทียบเพื่อหาคะแนนต่ำสุด (min)
ถ้าคะแนนตั้งแต่ 7 คะแนนขึ้นไป ให้นับจำนวนผู้ผ่าน (pass)
เมื่อวนครบทุกข้อมูลแล้ว คำนวณคะแนนเฉลี่ยจาก
คะแนนรวม ÷ จำนวนนักศึกษา
วนลูปอีกครั้งเพื่อตรวจสอบนักศึกษาที่ได้คะแนนต่ำกว่า 5 และแสดงรายชื่อผู้ที่ควรทบทวนเพิ่มเติม
แสดงผลลัพธ์ทั้งหมด ได้แก่ คะแนนรวม ค่าเฉลี่ย คะแนนสูงสุด คะแนนต่ำสุด จำนวนผู้ผ่าน และผู้ที่ต้องทบทวน

กรณีศึกษาที่ 3 : Queue
ลำดับการทำงานของข้อมูล
สร้าง Queue<String> สำหรับเก็บหมายเลขผู้ป่วย
เพิ่มผู้ป่วย P001 ถึง P005 ลงใน Queue ตามลำดับการมาถึง
ตรวจสอบว่า Queue ว่างหรือไม่ด้วย isEmpty()
ใช้ remove() จำนวน 2 ครั้ง เพื่อเรียกผู้ป่วย P001 และ P002 เข้ารับบริการ
เพิ่มผู้ป่วยใหม่ P006 และ P007 เข้าท้ายคิว
ใช้ peek() เพื่อตรวจสอบผู้ป่วยคนถัดไปโดยไม่ลบออกจากคิว
ใช้ size() เพื่อแสดงจำนวนผู้ป่วยที่ยังรออยู่
แสดงสถานะของ Queue หลังจากดำเนินการทั้งหมด
